## Definition

**Neural Network Model Calibration** (often called the "Two-Step Approach") uses deep neural networks to accelerate the calibration of complex financial models (e.g., Heston, SABR, or Rough Volatility). Instead of solving expensive PDEs or Monte Carlo simulations in real-time, a neural network is trained **offline** to learn the mapping from model parameters to option prices. Once trained, the network serves as a near-instantaneous surrogate for the pricing map during **online** calibration.

## Key Formula

The calibration problem aims to find parameters $\theta^*$ that minimise the difference between model prices $P(\theta, \zeta)$ and market prices $P_{\text{MKT}}(\zeta)$:

$$\theta^* = \arg\min_{\theta \in \Theta} \sum_{\zeta \in \mathcal{Z}} w_\zeta \left( P(\theta, \zeta) - P_{\text{MKT}}(\zeta) \right)^2$$

In the two-step approach, we replace $P(\theta, \zeta)$ with a neural network approximation $F_\phi(\theta, \zeta)$:

1.  **Offline Phase:** Train $F_\phi(\theta, \zeta) \approx P(\theta, \zeta)$ using synthetic data $(\theta_i, P_i)$ generated by the "true" model.
2.  **Online Phase:** Solve the minimisation using $F_\phi$. Because $F_\phi$ is a differentiable neural network, gradients $\frac{\partial F}{\partial \theta}$ are available via backpropagation, making the optimiser extremely fast.

## Example

Calibrating a **Rough Bergomi** model, where pricing a single option via Monte Carlo takes several seconds. Standard calibration across a grid of 50 strikes and maturities would take minutes. By training a Deep Neural Network (DNN) to learn the rough vol pricing map (taking $\sim$10 hours offline), the online calibration can be performed in under **50 milliseconds**. This allows the model to be used in real-time trading environments where volatility surfaces must be updated continuously.

## Remember

The two-step approach shifts the computational burden from the trader's desk to the training server. The **offline** phase is a "learning the model" step that needs to be done only once. The **online** phase is as fast as using a closed-form Black-Scholes formula, even for models that have no closed-form solution. This "Neural Calibration" is the primary reason why advanced models like **rough volatility** have become practically viable in institutional finance.
