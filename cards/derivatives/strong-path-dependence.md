# Strong Path Dependence

**Created:** 2026-06-13

## Definition

An option is **strongly path-dependent** if its payoff depends on the full sequence of asset prices $\{S_{t_1}, \ldots, S_{t_N}\}$ in a way that cannot be compressed into a small number of continuously-evolving state variables. No finite augmentation of the Black–Scholes PDE suffices; instead, **Monte Carlo simulation** over many complete price paths is the standard pricing method.

## Key Formula

The Monte Carlo price for a strongly path-dependent payoff $\Pi$ is:

$$V = e^{-rT}\,\mathbb{E}^{\mathbb{Q}}\!\left[\Pi\!\left(\{S_{t_i}\}_{i=1}^N\right)\right] \approx \frac{e^{-rT}}{M}\sum_{j=1}^{M} \Pi\!\left(\{S^{(j)}_{t_i}\}\right)$$

where $M$ is the number of simulated paths, each generated by:

$$S_{t_{i+1}} = S_{t_i}\exp\!\left[\!\left(r - \tfrac{1}{2}\sigma^2\right)\!\Delta t + \sigma\sqrt{\Delta t}\;Z_i\right], \quad Z_i \overset{\text{i.i.d.}}{\sim} N(0,1)$$

The Monte Carlo standard error falls as $1/\sqrt{M}$, so halving the error requires quadrupling the number of paths.

## Example

A **range accrual** pays a coupon proportional to the number of daily fixings the underlying spends inside a corridor $[L, U] = [90, 110]$ over $N = 252$ trading days. Annualised coupon rate 8%:

$$\Pi = 0.08 \times \frac{1}{252}\sum_{i=1}^{252} \mathbf{1}\{90 \leq S_{t_i} \leq 110\}$$

No single running statistic (average, maximum) captures how many days $S$ was inside the corridor — the full sample $\{S_{t_i}\}$ is needed. With $M = 100{,}000$ simulated paths, the expected coupon is estimated as the average of $\Pi$ across paths, typically converging in seconds.

## Remember

Strong path dependence drove the adoption of Monte Carlo pricing in banks through the 1990s. Structured products desks routinely sell range accruals, cliquets, and target-redemption forwards — all strongly path-dependent — where the payoff depends on hundreds of daily price fixings. A PDE approach would need one dimension per fixing date, requiring a $100^{252}$-node grid for a daily-monitoring range accrual, which is computationally impossible. Monte Carlo, by contrast, scales linearly in the number of paths regardless of how many fixings the payoff depends on, making it indispensable for modern structured products pricing.
